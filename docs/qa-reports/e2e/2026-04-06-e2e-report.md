## 升级阻断项

**XcodeBuildMCP UI 自动化与 visionOS 26.2 不兼容**

- 症状：`snapshot_ui` / `tap` 报 `NSInternalInconsistencyException: Could not obtain OS for model 'iPhone 6'`
- 根因：FBSimulatorControl 无法识别 visionOS 26.2 simulator，回退到 iPhone 6 fallback 失败
- 影响：P0 菜单交互、端到端交互链路无法通过 UI 自动化验证，必须真机手动
- 建议：等待 XcodeBuildMCP 更新对 visionOS 26.x 的支持，或使用 XCUITest 框架编写交互测试
