# 远程读取管线：模型、策略与验收

本文定义远程读取的统一模型、策略与验收方法，覆盖所有远程源与所有容器格式。本地源直读文件，不进管线。

## 原则

1. 带宽 B、延迟 L 是运行时探测值，不是常量。
2. 验收判据用比例表达。绝对毫秒只作为某次测量的快照，不进入目标。
3. 同一套策略在任意 B、L 下应接近各自的下界。换网络、换源、换文件都能应对。
4. 参数由探测值推导。代码中不允许出现与具体网络或具体文件绑定的常数。

## 模型

| 符号 | 含义 | 来源 |
|---|---|---|
| L | 单次请求往返延迟 | 运行时探测 |
| B | 稳定吞吐 | 运行时探测 |
| σ | 延迟抖动 | 运行时探测 |
| M_meta | 元数据字节数 | 布局探测 |
| M_first | 首帧所需字节数 | 容器探测 |
| r(t) | 内容码率曲线 | 播放列表、边播边测 |
| C | 缓冲上限 | 内存预算 |
| T_parse | 元数据解析时间 | 本地对照 |

```
打开    T_open  = L + M_meta / B + T_parse
起播    T_start = L + M_first / B + T_init
seek    T_seek  = L + M_seek / B + T_decode
稳态    零停顿 ⇔ max_t( ∫r − B·t ) ≤ C
```

`T_parse` 与 `T_decode` 是 CPU 成本，与网络无关，由本地对照测定。L 可被并行隐藏，B 不能。所有公式对任意 B、L 成立。

## 参数推导

```
块大小      block = clamp(B × L, 64 KiB, C / 8)
预取窗口    W = B × 目标时延
并发度      D = 1 + ceil(L ÷ (block / B)) = 1 + ceil(B × L ÷ block)
预取深度    B_req = max_t( ∫r − B·t )，上限为 C
预取起点    seek 后从目标位置起算，不预取无关区间
```

- 目标时延是唯一可调量，按场景给定：打开 0，播放由 B_req 决定。
- 并发度含 1 个在途请求：`ceil(L ÷ (block / B))` 只覆盖并行度，单独使用在 `block = B × L` 时退化为 1，吞吐上限为 `B / 2`。
- 当 B 或 L 变化超过 20% 时重新推导，不重启会话。
- 探测未完成前使用保守值，探测完成后切换，切换不丢缓存。
- 规划取值用最近一次探测；历次探测的最小值只用于超时与降级判定。
- 块大小只在缓存为空且无在途请求时更改；有缓存时保持原值，避免块索引与缓存失配。

## 探测

目标：得到 L、B、σ、错误率、可寻址性与内容长度。原则是先被动后主动，探测不阻塞首屏，不单独发无用请求。

| 量 | 方法 | 额外代价 | 说明 |
|---|---|---|---|
| L | 小请求（≤4 KiB）的完成时间，取最小值与中位数 | 一次往返 | 必须与真实读同类的冷请求；网络与回源合并计为 L_total |
| B | 在途并发请求的字节数除以时间，滑动窗口 EWMA | 0 | 单流可能不饱和，取并发后的聚合吞吐 |
| σ | L 样本标准差 | 0 | 用于对冲请求数量与超时 |
| 错误率 | 失败计数除以请求计数 | 0 | 熔断阈值来源 |
| 可寻址 | 一次 `bytes=0-0` | 一次往返 | 与首个 L 样本合并 |
| 内容长度 | 206 的 Content-Range | 0 | 首次读取顺带获得 |
| 元数据范围 | 布局探测读目录项与索引 | 一到两次读 | 打开路径必需，不能省 |

代价：

- 首次估计在 2 到 3 个真实请求后可用，通常不超过 1 秒。
- 主动探测只有一个小请求，约一个往返；带宽探测借用预取或元数据预取本身，不额外发请求。
- 探测在首屏之前只取已有请求的样本，不插入新请求；首屏后再按需补充。

更新规则：观测吞吐或延迟与估计偏差超过 20% 时重估；不设固定探测周期。

初始值：探测完成前使用保守值（L = 100 ms，B = 10 MB/s），首个真实请求后替换。

辨识方法：小请求由 L 主导，大请求由 B 主导。请求尺寸单一时，用两种尺寸或并发请求分离两个参数。L 与 B 不可从单次测量同时得到。

测量位置：探测在回环之后、源适配器之前进行，测得的是源的真实行为；回环的本地开销不计入 L 与 B。

冷热差异：源有缓存时，冷请求与热请求的延迟差可达数倍。L 取近窗样本的 p90 作为规划值，避免低估。

## 源行为的两区制

实测样本（4 MiB 块，起止时间与并发数来自 `probeSamples`）：

| 阶段 | 并发 | 字节 | 耗时 | 聚合速率 |
|---|---|---|---|---|
| 预取 | 2 | 8 MiB | 1.06 s | 7.9 MB/s |
| 顺序 | 1 | 4 MiB | 0.66 s | 6.4 MB/s |
| 突发 | 8 | 32 MiB | 1.33 s | 25 MB/s |

同一条源存在两种速率：冷块约 8 MB/s，刚被服务端缓存的块可达 25 MB/s。延迟由低并发样本推算为 0.06 到 0.13 s，与 HEAD 的 68 ms 一致；此前记录的 300 ms 是冷读总耗时，不是纯往返。

结论：单一 B 无法同时描述冷读与热读。模型按场景取用两个量。

```
B_sustained  近窗内并发窗口的最小聚合速率，用于预取深度与缓冲推导
B_burst      近窗内并发窗口的最大聚合速率，用于打开超时与首屏预算
```

探测输出两个值并标注置信度；参数推导用 B_sustained，超时与首屏用 B_burst。

## 归一化验收

| 场景 | 判据 |
|---|---|
| 远程打开 | T_open ≤ 1.25 × (L + M_meta / B + T_parse) |
| 本地打开 | T_open ≤ 1.25 × T_parse |
| 起播 | T_start ≤ 1.25 × (L + M_first / B + T_init) |
| seek | T_seek ≤ 1.25 × (L + M_seek / B + T_decode) |
| 需求期吞吐 | ≥ 95% B |
| 稳态（B 足够） | max_t( ∫r − B·t ) ≤ C 时零停顿 |
| 稳态（B 不足） | 停顿节奏与模型预测误差 ≤20% |
| 故障 | 注入 500、429、超时、截断、ETag 变化后按契约降级或恢复 |

判据对任意 B、L 成立，不需要为不同网络设置不同阈值。

## 多网络条件验证

合成源必须扫描参数网格，证明同一策略在每一点都接近下界：

| B | L | 验证重点 |
|---|---|---|
| 1 MB/s | 300 ms | 低带宽下不挂起，停顿节奏符合预测 |
| 2 MB/s | 100 ms | 打开仍接近 L + M/B + T_parse |
| 8 MB/s | 300 ms | 延迟隐藏生效，吞吐不低于 95% B |
| 20 MB/s | 50 ms | 大块与小并发下的利用率 |
| 50 MB/s | 5 ms | 本地级带宽下不出现过度预取 |

每格至少断言：打开时间、需求期吞吐、停顿节奏三项。

前两项已由参数网格测试覆盖。停顿节奏需要可限速的源才能制造 B 不足的条件；当前环境只有真实网络源，该项标记为阻塞。

## 本地源

本地文件不进管线，走独立快路径：`file://` URL 交给 libbluray，在 detached utility 任务里直接 POSIX 读，无回环、无逐次异步桥接、无探测。

实测（47.8 GB ISO）：

| 项 | 数值 | 说明 |
|---|---|---|
| 打开总时间 | 144 到 168 ms | 内部时间戳 |
| 目录加载 | 129 到 152 ms | libbluray 解析 |
| 卷随机 4 KiB 读 | 0.15 ms | 中位数，8 次采样 |
| 卷 1 MiB 读 | 0.59 ms | 单次 |

libbluray 打开期间的全部读加起来不足 2 ms，目录加载的其余时间用于 UDF 遍历与索引解析。本地读路径没有可压缩的空间；可改的只有重复打开命中目录缓存，以及解析层本身。

本地验收：打开 ≤0.2 s；重复打开命中缓存；吞吐不低于卷上限 90%。

## 契约

| 契约 | 内容 |
|---|---|
| 读取 | `read(range) → bytes`，校验 206 与 Content-Range 一致；不一致即失败 |
| 打开 | 所有容器走同一布局探测接口：ISO 探测 BDMV，MP4 探测 moov，MKV 探测 cues；打开有上界，超时报告降级 |
| 鲁棒性 | 幂等读重试与指数退避；尾延迟用对冲请求；熔断与降级；取消；缓存内存上限 |
| 分配 | 需求读优先：需求读耗时中位数超过 4 × L 时暂停预取，回落后自动恢复 |
| 一致性 | 身份（ETag、大小、修改时间）变化时失效对应缓存 |

## 测试装置

**单元与模型测试**

- 参数网格：B ∈ {1, 2, 8, 20, 50} MB/s，L ∈ {5, 50, 300} ms。已断言需求期吞吐 ≥ 95% B 与打开上界 ≤ 1.25 ×（L + M/B）；停顿节奏待补。
- 码率曲线：恒定、前低后高、锯齿三种形态，断言停顿节奏。
- 故障注入源：500、429、截断响应、错位 Content-Range、ETag 变化，断言重试、熔断、缓存失效。
- 取消测试：seek 时在途预取被取消，无泄漏。

**集成验收**

- 测试通道动词：`openSourceFile`、`fileBrowserState`、`playDiscTitle`、`seekNormalized`、`playbackProbe`、`streamStats`。
- 内部计时日志：`disc.open.start`、`disc.open.resolved`、`disc.open.prewarm`、`disc.catalog.loaded`、`disc.open.ready`；`playback.seek.start`、`playback.seek.ready`。
- 首帧时间：`playback.command` 与 `playback.firstFrame` 两条日志，均带绝对时间戳。
- 打开时间以内部日志为准。

**网络条件**

- 本机 WebDAV 仅作为低延迟对照。
- 代理限速与固定延迟，覆盖参数网格中的代表点。
- 播放中断网再恢复，验证重连与恢复。
