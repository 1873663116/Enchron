# solutions/ — 可迁移经验（时间戳记录）

入册规则：

- frontmatter 必带 `date`、`applies_when`（什么情况下该查我）与 `expires_when`（什么变化让我过期）。
- 记录「当时为真」的踩坑与解法，不承诺「现在为真」；正文不随项目演进维护。

流转规则：

- 被反复引用（约第三次）→ 候选晋升为 skill 或 skill reference；只有程序性、会重复的知识值得晋升。
- `expires_when` 触发或描述已死架构 → 移入 `docs/archive/solutions/`。
- 每轮收尾清扫时审视（见 CLAUDE.md 会话协议）。

子目录：`best-practices/`（经验模式）、`build-errors/`（构建错误诊断）。
