# Compound: 播放模式约束是几何兼容性问题，不是层级问题

**Date**: 2026-04-05
**Context**: 播放模式层级约束需求调查

## 洞察

最初的问题框架是"2D 视频不应该升级到沉浸/全景模式"。调查后发现这个框架是错的。

实际的约束是**几何兼容性**：
- **全景模式**将画面投射到球面（PanoramaSphereEntity）→ 只有全景内容（180/360/fisheye）在球面上才有正确的几何映射
- **沉浸影院模式**将画面投射到虚拟平面屏幕（VirtualScreenEntity + EnvironmentDomeEntity）→ 所有内容类型都能正确呈现

因此，flat → immersive 完全合法（这是产品的核心差异化 — 在虚拟影院里看 2D 电影）。被限制的只是 flat/stereo → panorama（几何不兼容）。

## 为什么这不显然

1. 用户报告的症状是"2D 切到沉浸/全景都出错"，但实际上只有 panorama 出错
2. "层级"心智模型暗示 flat < stereo < panoramic 的线性顺序，诱导出"低层不能往上走"的规则
3. 真正的模型是二维的：渲染方式（平面/球面）× 内容类型（flat/stereo/panoramic），不是一维层级

## 可迁移经验

当用户报告的问题涉及多个模式组合时，先验证每个组合的实际渲染结果，不要从问题描述直接推导约束模型。问题描述往往过度泛化。
