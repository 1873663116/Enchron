# 车道耦合问题方案

本文是音频与字幕在切换、跳转之后出现静音、丢字幕、错位的唯一验收依据。状态变化时更新本文。

## 一、现象与原始输出

一，切换音轨后视频继续、声音没有，跳转一次后恢复。

```
21:53:57.718  audio.select.request index=1
21:53:57.775  audio.attach.open reason=selection index=1 codec=truehd
              queuedBefore=43098 queuedAfter=74324 headBefore=1300.815 sourceStart=0.000
```

切换发生在播放位置约 1315 秒处，新车道拿到的队头在 1300.815 秒，落后约十四秒。此后没有任何丢弃或对齐日志。

二，字幕在切换与跳转之后错位或整段消失。字幕车道同样按队列取包，队头可能早于或晚于播放位置。

三，切换在某些片段无缝，在某些片段中断。区别在于新选中的流当时队列里有多少包：队列长则中断时间长，队列刚好在播放位置附近则几乎无缝。

## 二、共同原因

共享源给每条流维护队列，读取线程对**所有**音频与字幕流持续入队，不管有没有车道在消费。队列没有播放位置的概念：只有入队，没有按播放位置裁剪。

车道挂载时只能取队头，于是挂载位置等于队列里最老的包，而不是播放位置。

```
读取线程    ──入队──▶  流队列(队头在 1300.8)  ──取出──▶  音频车道(播放位置 1315)
                                    ▲
                                    └── 没有「丢弃播放位置之前的包」这一步
```

视频不受影响，因为视频读取器创建时就带起始位置，源按位置裁剪。音频与字幕没有这个契约。

跳转能恢复，是因为跳转重建队列，队头被迫回到播放位置。

## 三、目标一：挂载位置等于播放位置

行为。选中音频或字幕、跳转之后三条车道（视频、音频、字幕）都从播放位置开始取包，不从队列最老的包开始。

观测。挂载日志里的 `headBefore` 与当时的播放位置相差不超过一秒。

失败。挂载日志的队头落后播放位置超过一秒，且随后十秒内没有追平。

结构。车道挂载只有一个入口，入口接收位置参数；源按该位置裁剪队列。

## 四、目标二：静音要么不存在，要么被说清楚

行为。已选中的车道断流时，会话先自愈：把该车道重新锚到播放位置。自愈不成功且断流持续超过一秒时，界面才给出可感知的提示。一秒以内的短暂断流不改变界面状态，不打断观看。

观测。日志记录断流开始、自愈尝试、自愈结果三个时刻。界面提示只在自愈失败之后出现。

失败。断流超过一秒且自愈未发生、界面也没有任何提示，用户看到画面在播、声音消失。

结构。断流检测在会话层，针对车道；自愈复用目标一的「按位置挂载」入口，不新增路径。

判断依据。三百毫秒的断流在正常切换里很常见，为它弹加载会让每次切换都闪一下，比短暂静音更烦人。用户真正不能接受的是长时间静音却毫无解释、要自己跳转才能恢复。

## 五、目标三：切换音轨在一次采样边界上完成

行为。用户确认新音轨后，界面立刻显示新音轨为已选中，菜单不阻塞。声音在两百毫秒内切换到新音轨。切换点上旧音轨先静音，新音轨后出声，两者不重叠。

观测。日志记录请求时刻、新车道就绪时刻、旧车道静音时刻、新车道出声时刻。四个时刻的差决定是否达标。

失败。切换后出现两条音轨同时出声；或旧音轨先停超过两百毫秒新音轨才出声；或界面显示的已选中音轨与实际出声的音轨不一致。

结构。切换是同一时刻的原子交换：静音旧的与启用新的在同一个采样边界完成。不做交叉淡入淡出。

判断依据。两条音轨内容不同，交叉淡化会让人同时听到两种语言或两段评论，比短暂静音更糟。界面先响应，是因为用户已经明确表达了选择；声音稍后到位，只要在两百毫秒内就感觉不到延迟。

## 六、不变量

一，连续播放十分钟，音画同步且字幕跟随，无静音段。

二，跳转后三秒内三条车道都从新位置继续。

三，切换音轨三次，每次界面在两百毫秒内显示新音轨且声音到位，不出现双音轨同时出声。

四，切换字幕三次，每次字幕都在一秒内出现，且不出现旧字幕残留。

五，上述四项在慢速源与本地源上各跑一遍。

## 七、执行顺序

一，先做目标一。它同时解释静音与丢字幕两个现象，改动集中在源与挂载入口。

二，再做目标二。它是安全网：即使还有残余的挂载错误，也不会表现成「画面在播、声音消失」。

三，最后做目标三。它依赖前两项的队列裁剪与状态机。

## 八、未决

一，队列为何会积累到七万个包（约四十分钟音频）尚未查明；读取线程对所有音频流入队且从不裁剪。

二，字幕在跳转后的重建路径与音频不同，两条路径需要收敛到同一个挂载契约。

三，断流自愈的重试节奏未定：一次自愈失败后多久再试、上限几次。
