# Phase 8：表冠收起行为

[overview](overview.md)

## Goal

表冠退出沉浸落回同族主窗口呈现（panorama→portal、docked→window），播放继续；替代现有"意外丢失→尝试恢复沉浸"对表冠场景的误判。

## Changes

phase-5 已实证单按场景无窗口可保留且恢复机制会抢回聚焦对抗用户，故机制定为：系统发起的沉浸空间关闭一律落回同族主窗口呈现（空间关闭事件即时开 portal/window 并继续播放），不再尝试重回沉浸；"意外丢失自动重回沉浸"的恢复语义整体废除，空间因故障消失时用户经族内按钮重进。表冠旋转与沉浸量归系统所有，App 不监听、不基于沉浸量触发任何行为。恢复机制的删除在 phase-9 清理。

## Verification

设备：表冠单按、双按两个场景的录屏与探针时间线。
