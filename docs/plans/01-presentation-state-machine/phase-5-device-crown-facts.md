# Phase 5：表冠真机事实（已裁决，无剩余工作）

[overview](overview.md)

## 裁决（2026-08-11 佩戴者在 visionOS 27 真机实测，panorama 呈现、无 App 窗口共存）

- 表冠在渐进沉浸下归系统所有：旋转在 0.3–1 区间调节沉浸量，真机行为正常；到达下限 0.3 后系统不允许继续下旋（钳制在下限，不关闭空间）。App 不监听沉浸量，也不基于沉浸量触发任何行为。基于沉浸量的"主动收起"与系统的表冠语义冲突，属于与恢复机制同类的对抗系统输入，不实现。
- 单按表冠：系统关闭沉浸空间并直达 Home View（无窗口可保留）；当前 App 的恢复机制立即重开沉浸空间抢回聚焦，可无限重复。恢复语义对表冠场景的误判被实证，phase-8 的收起行为以此为据。
- 双按表冠：系统级"内容与现实环境切换"手势（伴系统提示音），空间隐藏而非关闭，再按返回；与 App 无关，不需要处理。
- "空间与窗口共存时单按只关空间"的分支在 Enchron 当前形态不可达（进沉浸即关主窗口）；若 phase-7/8 的实现引入共存窗口再行验证。

## Changes

无。收起（phase-8）唯一的触发是系统发起的沉浸空间关闭事件，与沉浸量无关。
