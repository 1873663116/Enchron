# Phase 5：表冠真机事实（实验）

[overview](overview.md)

## Goal

补齐旋转维度的仪器化证据：`onImmersionChange` 的回调粒度、下限值送达可靠性、旋转到下限后的系统行为。

## 已裁决（2026-08-11 佩戴者在 visionOS 27 真机实测，panorama 呈现、无 App 窗口共存）

- 单按表冠：系统关闭沉浸空间并直达 Home View（无窗口可保留）；当前 App 的恢复机制立即重开沉浸空间抢回聚焦，可无限重复。恢复语义对表冠场景的误判被实证，phase-8 的收起行为以此为据。
- 双按表冠：系统级"内容与现实环境切换"手势（伴系统提示音），空间隐藏而非关闭，再按返回；与 App 无关，不需要处理。
- "空间与窗口共存时单按只关空间"的分支在 Enchron 当前形态不可达（进沉浸即关主窗口）；若 phase-7/8 的实现引入共存窗口再行验证。

## Changes

只加取证探针，不改产品行为：沉浸空间挂 `onImmersionChange` 探针记录 amount 序列与时间戳；佩戴者旋转表冠至下限并继续下旋，探针与录屏取证。

## Verification

证据文件落 TestEvidence；旋转结论回填 phase-8 的收起触发设计。
