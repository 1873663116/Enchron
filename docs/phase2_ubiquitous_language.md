# Phase 2 产出：通用语言词汇表

> 本表定义了 Endorphin Player 项目中开发与设计团队必须统一使用的业务词汇。代码中的命名必须与此表一致。

## 核心业务实体

| 术语 | 定义 | 代码命名 |
|---|---|---|
| 媒体文件 | 可被播放器识别和播放的视频文件 | `MediaFile` |
| 文件夹 | 文件的组织容器，可以来自本地或远程数据源 | `MediaFolder` |
| 数据源 | 文件的来源，包括本地文件系统、Apple 相册、SMB 服务器、WebDAV 服务器 | `DataSource` |
| 存储连接 | 用户配置的一个远程文件服务器的连接信息（地址、凭证、协议类型） | `StorageConnection` |
| 播放进度 | 某个媒体文件的播放位置记录（分:秒） | `PlaybackProgress` |
| 播放会话 | 从用户选择一个媒体文件开始播放到播放结束/退出的完整生命周期 | `PlaybackSession` |

## 媒体画面特征

| 术语 | 定义 | 代码命名 |
|---|---|---|
| 媒体画面特征 | 视频文件的投影类型 + HDR 类型 + 分辨率的综合描述 | `MediaProfile` |
| 投影类型 | 视频的空间投影方式：平面/SBS 左右/OU 上下/360° 全景/180° VR/鱼眼 | `ProjectionType` |
| HDR 类型 | 视频的动态范围类型：SDR/HDR10/HDR10+/杜比视界/HLG | `HDRType` |
| 播放模式 | 当前视频的渲染方式：窗口模式/沉浸场景模式/全景模式 | `PlaybackMode` |

## 播放控制相关

| 术语 | 定义 | 代码命名 |
|---|---|---|
| 播放状态 | 当前播放会话的状态：播放中、暂停、缓冲中、已停止 | `PlaybackState` |
| 倍速 | 播放速率倍数（0.25x ~ 5.0x） | `PlaybackSpeed` |
| 音轨 | 视频文件中的一条音频流，一个文件可能包含多条不同语言的音轨 | `AudioTrack` |
| 字幕轨 | 视频文件中嵌入的或外挂的字幕数据 | `SubtitleTrack` |
| 二级进度条 | 点击标准进度条后切换到的可缩放时间轴视图 | `DetailedTimeline` |
| 选集 | 当前文件夹下所有视频文件的列表，用于快速切换播放 | `Playlist` |

## 手势相关

| 术语 | 定义 | 代码命名 |
|---|---|---|
| 捏合 | 拇指与食指捏合的基础动作 | `PinchGesture` |
| 单次捏合 | 捏合后 200ms 内无后续动作，唤出主菜单 | `SinglePinch` |
| 双击捏合 | 200ms 内连续两次捏合，切换播放/暂停 | `DoublePinch` |
| 长按捏合 | 捏合后持续保持，激活 2.0 倍速 | `LongPinch` |
| 拖拽捏合 | 长按后水平拖拽，拉动进度条 | `DragPinch` |
| 手势消歧 | 在 200ms 观察窗口内判断捏合类型的状态机 | `GestureDisambiguator` |

## 空间场景相关

| 术语 | 定义 | 代码命名 |
|---|---|---|
| 虚拟场景 | 沉浸空间中的 3D 环境（如影院、太空等主题场景），由 Reality Composer Pro 制作 | `VirtualEnvironment` |
| 虚拟屏幕 | 沉浸空间中用于显示视频画面的平面实体 | `VirtualScreen` |
| 全景球体 | 全景模式下包裹用户的球体/半球体，视频投射在内壁上 | `PanoramaSphere` |
| 屏幕位置 | 虚拟屏幕的远近距离和垂直高度设置（每个场景独立记忆） | `ScreenPosition` |
| 视角旋转 | 虚拟屏幕沿 X 轴旋转角度，适配不同观影姿势 | `ViewAngle` |

## 状态与异常

| 术语 | 定义 | 代码命名 |
|---|---|---|
| 网络状态 | 远程连接的当前状态：已连接、缓冲中、已断开 | `NetworkStatus` |
| 重连 | 网络断开后后台自动尝试恢复连接 | `Reconnection` |
| 进度记忆 | 退出播放后自动保存进度，下次打开时提示恢复 | `ProgressMemory` |
