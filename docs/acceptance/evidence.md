# Enchron 当前真机验证证据

本文件只记录当前候选版本在物理 Vision Pro 上实际执行的回归结果。验证要求见 [`verification-system.md`](verification-system.md)，完整场景见 [`regression-matrix.md`](regression-matrix.md)。

当前没有完成整套必过矩阵并且仍与当前产品代码树一致的真机结果，因此发布验证状态为未评估。构建成功、合同测试、历史设备运行或部分场景通过不能改变这一状态。

新的结果必须记录候选产品代码树身份、Xcode 与 visionOS 版本、物理设备环境、测试媒体内容摘要、场景编号、`.xcresult`、状态附件、截图或录屏、性能记录，以及适用时的外置麦克风录音和佩戴者验收结论。
