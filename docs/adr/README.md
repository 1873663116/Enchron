# ADR — 架构决策记录

何时写 ADR（三条全满足才写）：

1. 难以逆转——之后改主意的代价是实质性的；
2. 缺上下文会让未来读者困惑"为什么这样做"；
3. 真实权衡的产物——存在过认真的替代方案。

格式：标题即决策、状态、日期、背景、决策、考虑过的替代方案、后果。先例：本目录 `0001-collaboration-constitution.md`；mpv fork 仓库的 `xr-fork/adr/`。
