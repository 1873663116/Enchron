宪法七条（协作的游戏规则，全文在 CLAUDE.md 顶部）

  1. 双全景——你和任何新 agent 五分钟内能答：在哪、干嘛、下一步、谁执棒。
  2. 按需加载——agent 文档分常驻/触发/按需/冷库四层；常驻层有预算，进一字挤一字。
  3. 人类层单向——本页这类人类层，agent 只写不读；错了重建，不传染。
  4. 真相时态——每份文档属于：活法律 / 时间戳记录 / 工作态 / 人类投影。
  5. 证据与验收——动工前写验收条件，「完成」必须挂证据。
  6. 固定节奏自清洁——每轮收尾清扫；堆积是节奏失守，不是分类不够。
  7. 一切可推翻——宪法高于旧指示；修宪写 ADR 留痕。

sRGB 色彩契约（_srgb / Unlit）写读两端约好同一种「曝光参数」，否则画面发白（ADR 0004 的教训）🟡
XCFramework / MPVKit把 mpv 全家桶打包成 Xcode 认识的积木盒🟡
RCP（Reality Composer Pro）3D 场景的剪辑室，产出 .usda 资产🟡
双缓冲 / front 发布「写完才举牌」：front ID 永远指向最新完整的一帧🟡
issue 状态机open 是唯一要管的水位（一屏放得下）；closed 是免费冷库，关闭≠删除🟡
Closes #N缝合针脚：PR 合进默认分支的瞬间自动关单并互挂链接🟡
开便宜、关昂贵堆积的力学原理：开 issue 只要念头，关 issue 需要决定；治理靠节奏不靠分类🟡
