概念地图（边实践边学）

掌握度：✅ 已懂 ｜ 🟡 模糊 ｜ ⬜ 未接触。改标记：告诉 agent 或直接编辑本文件。术语定义以 CONTEXT.md 为准。
概念一句话（比喻版）掌握度
FrameExit 帧出口放映机的光从哪个口出来：直接打到幕布（swapchain）或先写进底片库（residentTexture）🟡
ResidentTextureRing 常驻纹理环两张轮换的底片：mpv 写一张、你读另一张，永不读到写一半的🟡
PresentationSurface 呈现表面三块幕布：窗口平面 / 虚拟屏 / 全景球。模式切换=换幕布🟡
PlaybackMode vs PlaybackEngineRoute「在哪看」（呈现决策）vs「谁来播」（引擎路由），刻意分开的两个词🟡
IOSurface系统级共享相纸：两个进程/两套图形 API 看同一块显存🟡
CAMetalLayer / swapchain窗口的画框+轮换画布，画完一张换下一张直接上屏🟡
vo=gpu-next / libplacebompv 的高质量渲染管线（缩放、色彩、HDR 的发生地）🟡
MoltenVK / Vulkanmpv 说 Vulkan 语，Apple 只懂 Metal，MoltenVK 是同声传译🟡
VK_EXT_metal_objects传译员的特殊通道：让 Vulkan 直接拿 Metal 的纹理（C6 赌的就是它）🟡
LowLevelTexture / TextureResourceRealityKit 接收外部画面的两种插座🟡
sRGB 色彩契约（_srgb / Unlit）写读两端约好同一种「曝光参数」，否则画面发白（ADR 0004 的教训）🟡
XCFramework / MPVKit把 mpv 全家桶打包成 Xcode 认识的积木盒🟡
RCP（Reality Composer Pro）3D 场景的剪辑室，产出 .usda 资产🟡
双缓冲 / front 发布「写完才举牌」：front ID 永远指向最新完整的一帧🟡
