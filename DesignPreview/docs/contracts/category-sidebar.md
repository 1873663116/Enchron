# 组件契约:`CategorySidebar`(静态大类分类器侧栏)

> 状态:已定稿(契约层)。**新组件**,待从内联的 `settingsSidebar` 抽取。
> 关系:与 `SourceSidebar` 是**两个不同角色**。本件无任何交互能力,是个静态分类列表。

## 0. 角色
通用的大类分类器侧栏:在 Settings 页面、Panel 面板中选择一个大类。天生没有重排、没有长按删除——就是个可选中的列表。当前以**内联 `settingsSidebar`** 形态散落在页面里,需抽取为标准件。

## 1. 构造
一个简单的标准件:标题 + 一列静态行。行视觉**直接复用现有的 `SourceSidebarRow`**(纯视觉行),不另画。无状态机、无 footer。

## 2. 变体
无。

## 3. 暴露参数
| 参数 | 能调什么 | 影响 | 证据 / 理由 |
|---|---|---|---|
| `items` | 分类条目(图标 + 标题) | 列出哪些大类 | 内容可变 |
| `selection` | 当前选中的大类 | 高亮哪一项 | 分类器核心 |
| `title`(可选) | 侧栏标题 | 顶部标题 | 可变 |
| `width` | 侧栏宽度 | 整体宽 | **成对暴露**:Settings 满宽 vs Panel 紧凑,容器管不了 |
| `height` | 侧栏高度 | 整体高 | **成对暴露**(只给宽不给高=体验差) |

## 4. 无障碍(硬要求)
- 稳定 `accessibilityIdentifier`(容器 + 各分类行可定位)。
- 行作为可选中元素,选中态需可被端到端测试读取。

## 5. 锁死
行视觉(复用 `SourceSidebarRow`)、玻璃、所有相关 token、配色——全锁。**无 capabilities、无 footer**。

## 6. 决策记录
1. 从 `SourceSidebar` **按角色拆出**(差异大到「一个有整套状态机、一个根本没有」,拆成两个简单组件优于一个带 flag 的复杂组件)。
2. `width` + `height`:**成对暴露**(本件唯一暴露尺寸的组件,因 Settings/Panel 容器尺寸不一)。
3. 待办:从内联 `settingsSidebar` 抽取为标准件(实现阶段)。
