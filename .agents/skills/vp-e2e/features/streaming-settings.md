# 串流设置

设置页的 Moonlight 分区决定下一次串流向主机请求什么。这些取值只影响下一次请求，不改变进行中的会话。

## Sub-features

- 分辨率按像素总量从小到大排列：1280×720、1920×1080、2560×1440、3360×1440、5120×1440、3840×2160，末项是自定义。
- 自定义分辨率的宽高由步进器调整，宽度范围 320 到 7680，高度范围 240 到 4320。
- 帧率取值为 30、60、90、120 fps。
- 码率滑杆是 19 档非等距取值，最高 200 Mbps，低段更密。
- 选择预设分辨率或帧率后，码率跳到该组合的建议值。
- 选择自定义分辨率后，码率不再跟随。
- 自定义码率开关打开前弹出警告，确认后滑杆灰显并出现输入框，接收 1 到 500 Mbps 的整数。
- 编码格式取值为自动、H.264、HEVC、AV1；本机不支持 AV1 解码时该选项不出现。
- HDR 标注 Beta，默认关闭。编码选择 H.264 时 HDR 显示为关并灰显。
- 帧调度是「平滑优先」与「延迟优先」二选一，默认延迟优先；平滑优先让视频多留一帧吸收网络抖动，延迟优先按到达时间立即安排呈现。
- 交换 ABXY 默认关闭；打开后 A 与 B、X 与 Y 的报文位互换，方向键、肩键与摇杆不变。
- 鼠标跟踪是回落菜单：相对与绝对二选一，默认相对。相对转发设备位移并锁定指针；绝对把设备位移积分成画面上的位置再发绝对指针报文。
- PC 端播放音频默认关闭；打开后主机在本地播放声音，本机不再解码音频。
- 优化游戏设置默认关闭；打开后向主机请求调整游戏内设置，仅 GeForce Experience 主机响应。
- 上述四项与分辨率、帧率一样，只影响下一次启动，不改变进行中的会话。

## How to get to it (user POV)

设置页左侧选 Moonlight。分区在 General 之下，包含会话配置与下一次连接使用的配置两行只读摘要。

## Driving it with computer use

Preconditions: 标签页已由 General 分区的 Moonlight 开关打开。

读取当前取值走命令通道，写入同样走命令通道：

```sh
./.scratch/stream-cmd.sh streamSetOptions '{"resolution":"2560x1440","fps":"60","codec":"hevc"}'
```

```sh
./.scratch/stream-cmd.sh streamSetOptions '{"customBitrate":"true","bitrate":"300000"}'
```

```sh
./.scratch/stream-cmd.sh streamSetOptions \
  '{"swapABXY":"true","audioOnPC":"true","mouseTracking":"absolute","optimizeGameSettings":"true"}'
```

`swapABXY`、`audioOnPC`、`mouseTracking`、`optimizeGameSettings` 的读写都走同一条通道。`audioOnPC` 与 `optimizeGameSettings` 的生效位置是启动请求，判据见下表；`swapABXY` 的生效位置是会话内的手柄报文；`mouseTracking` 的生效位置是会话内 GCMouse 到主机指针的换算。

分辨率的像素量排序、码率与分辨率和帧率的对应、自定义码率的上下限，都能由这条通道直接断言，不需要点开菜单。

菜单本身的下拉内容、滑杆的拖动手感、警告弹窗的文案属于界面呈现，需要读截图。

## 证明的终态

进入启动单元前，设置必须落到一个主机能接受的组合：分辨率是预设或合法的自定义尺寸，帧率在四档之内，码率在滑杆或自定义区间内，编码与 HDR 不构成主机忽略的组合。

## Gotchas

- **自定义码率打开时，码率不再随分辨率或帧率变化。** 这是佩戴者接过控制权的意思，不是联动失效。
- **命令通道改分辨率不会触发码率联动。** 联动写在菜单回调里。用命令通道验证联动会得出错误结论，要改用点击菜单。
- **H.264 与 HDR 同时存储时，读出的 HDR 是关。** 归一化在读取时发生，主机在 H.264 上本来就不会送 HDR。
- **交换 ABXY 只改本机发出的报文位，不发给主机。** Moonlight 协议没有按键交换参数，主机收到的仍是交换后的 A/B/X/Y 语义。
- **PC 端播放音频时本机收不到音频帧。** 声音留在主机，音频链路没有可断言的输入，判据只能取启动 URL。
- **优化游戏设置只对 GeForce Experience 主机有可观察效果。** Sunshine 接受参数但不调整游戏设置，不能据此判定失败。

## 本轮补齐范围（2026-10-26 裁决）

范围、阶段与验收见 `docs/reviews/streaming-port-review/plan.md`。

纳入：

- 三类新设置：鼠标跟踪（相对/绝对）、统计浮层开关、声道菜单（立体声／5.1／7.1）。画面区域不提供手部手势设置。
- 本机能力约束选项可用性：没有 HEVC Main10 硬件解码时 HDR 开关不可用；没有 HEVC/AV1 硬件解码时分辨率菜单不列出高于 1080p 的档位。存着的设置超出设备预算时，启动前钳制到 1080p 并留探针 `resolution clamped`。
- 主机声明的编解码能力只影响 HDR 文案的措辞，不禁用开关：主机报 0 表示它没有声明，不能据此判断它做不到。
- 新增设置项对旧记录有默认值，旧设置文件解码后不会失败。

不做：多手柄与屏幕控件两项设置（对应能力不做，避免出现拨了没反应的开关）；帧率按屏幕能力钳制。
