# design_docs/ — 参考归档

本目录下的文档已降级为**参考归档**。它们记录了项目 DDD 建模和架构设计的完整推演过程，保留历史价值，但不再作为 agent 日常工作的主要依据。

**主要依据**：根目录的 `ARCHITECTURE.md`。当本目录文档与 `ARCHITECTURE.md` 冲突时，以 `ARCHITECTURE.md` 为准。

## 何时查阅本目录

- 需要了解 DDD 建模细节（聚合根、实体、值对象的完整定义）→ `phase2_tactical_domain_model.md`
- 需要了解限界上下文的职责划分和协作关系 → `phase2_bounded_contexts_and_context_map.md`
- 需要了解模块间 protocol 接口的完整签名 → `phase3_interface_contracts.md`
- 需要了解分层实现的完整目录树 → `phase3_clean_architecture_structure.md`
- 需要查统一术语表 → `phase2_ubiquitous_language.md`（已复制到 `workspace-agents/ubiquitous_language.md`）
